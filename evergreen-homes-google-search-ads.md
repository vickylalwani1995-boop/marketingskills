# Evergreen Homes MI — Google Search Ads

**Prepared for:** evergreenhomesmi.com
**Skills used:** `paid-ads` (campaign structure, ad copy frameworks, audience targeting) + `copywriting` (headline formulas, CTA guidelines)
**Platform:** Google Ads — Search campaigns (Responsive Search Ads)
**Objective:** Lead generation — drive tour bookings and contact form submissions

## Keyword Targeting Strategy

### Match Type Approach (from `audience-targeting.md`)

**Phase 1 (Weeks 1–4): Tighter targeting**
- Primarily exact match and phrase match
- Build conversion data
- Identify top performers and search terms

**Phase 2 (Weeks 5–8): Expand carefully**
- Add broad match on proven keywords with smart bidding
- Use search terms report weekly to add negatives
- Layer audience targeting in "observation" mode

**Phase 3 (Ongoing): Scale winners**
- Consolidate budget into top-performing ad groups
- Expand geo-targeting if budget allows (South Lyon, Bloomfield, Novi)
- Test RLSA campaigns (different ads for returning visitors)

### Audience Layering

**Observation mode audiences (add to all campaigns):**
- In-market: "Residential Properties" > "Homes for Sale"
- In-market: "Real Estate" > "New Construction"
- Detailed demographics: Homeowners
- Detailed demographics: Household income (top 30%)
- Custom intent: People who searched for "custom home builder," "new construction homes," "build a house"

**Once you have data:** Increase bids on high-performing audiences, or create targeting-mode campaigns for best segments.

## Reporting Cadence

### Weekly Review

- Spend vs. budget pacing
- CPA per campaign and ad group
- Top search terms (add negatives, find new keywords)
- CTR by ad group (below 3%? Refresh headlines)
- Conversion rate by landing page
- Quality Score check (aim for 7+)

### Monthly Review

- Campaign-level ROAS/CPA trends
- Audience performance (observation mode data)
- Geographic performance (any zip codes over/underperforming?)
- Ad copy performance (which headlines/descriptions win?)
- Budget reallocation to top performers
